security & privacy notice

IP address exposure

Your real IP address will be visible to all peers, even when using a VPN. This is inherent to WebRTC P2P.

browser extensions

Malicious extensions can access all content including encryption keys. Use trusted extensions only.

no forward secrecy

If your device is compromised later, recorded messages could be decrypted. Avoid highly sensitive topics.

identity verification

Use the fingerprint button to verify peer identities. Compare out-of-band to prevent MITM attacks.

file sharing risks

Always scan downloads for malware. Files are not scanned. Only download from trusted sources.

how to use blckbx secure

01
security first
all messages, files, and voice are encrypted end-to-end with aes-256-gcm encryption and ecdh p-521 key exchange. no data is stored on servers. connections are peer-to-peer only.
02
choose room type
select private room for direct peer-to-peer connections or public room to browse, create, or join named rooms with multiple users. public rooms appear in the discovery browser.
03
discover & join
rooms are discovered through a gossip network - when you join a room, you learn about other active rooms from connected peers. the more rooms you join, the more you'll discover. alternatively, share room names directly for instant joining. all connections are end-to-end encrypted.
04
voice channels
join the voice channel to talk with all connected users. new users automatically connect when they join. voice is encrypted and peer-to-peer with no server relay.
05
file sharing (5gb limit)
share files up to 5gb with accept/reject prompts. when someone sends a file, you see the name, size, and type before accepting. files are encrypted, chunked, and sent p2p. executable files blocked. always scan downloads for malware.
06
safety features
built-in protection: rate limiting prevents spam, urls are validated and sanitized, malicious content is blocked, connections auto-recover from disruptions, and message history is never stored.
