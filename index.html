how to use blckbx secure

01
encryption keys
when you connect, ecdh key exchange automatically establishes shared encryption keys using elliptic curve cryptography p-521 curve. (nerdy ahh bum stuff)
02
share your id
click "copy id" and share your unique peer id with someone you want to connect with securely.
03
encrypted connection
paste their id and click "connect". all messages and files are encrypted with aes-256-gcm before transmission.
04
screen sharing
share your screen with connected peers by clicking "share my screen". viewers can close the screen share at any time.
05
themes
customize your experience with preset themes or create your own custom theme with the color picker, for more advanced themes creation modify the html file with a code editor.
