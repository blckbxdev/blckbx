how to use blckbx secure

01
choose room type
select private room for direct peer-to-peer connections or public room to browse, create, or join named rooms with multiple users.
02
browse public rooms
discover active public rooms and join with one click. rooms are listed with their names and user counts.
03
encryption keys
when you connect, ecdh key exchange automatically establishes shared encryption keys using elliptic curve cryptography p-521 curve.
04
private rooms
share your unique peer id with someone you want to connect with securely. paste their id to establish an encrypted connection.
05
create public rooms
create a room with a name and it will appear in the public room browser. share the room code for direct access. all messages and files are encrypted with aes-256-gcm.
06
screen sharing & files
share your screen with connected peers or transfer encrypted files. all data is protected with end-to-end encryption.
