blckbx; secure pure p2p chat (v1.4 / v1.5 beta)
blckbx is a secure, browser-based, purely peer-to-peer chat interface designed for privacy-conscious users. no central message storage. no accounts. just encrypted, direct communication between peers.

run blckbx:
live (v1.4): https://blckbxdev.github.io/blckbx/
local (up to v1.5 beta): download the html file and open it in your browser. 

features:
v1.4 (stable)

fully p2p encrypted messaging

private rooms using unique ids

no servers storing chat logs

v1.5 beta

public rooms (no code required to join)

experimental ui layouts and new internal systems

sanitized links, files, gifs, and media handling

improved private room stability

note: the beta introduces major ui and system changes. some layouts may not render correctly and certain features may behave unexpectedly. public rooms are experimental; private rooms remain fully functional and improved.

security overview

end-to-end encrypted communication

the room id functions as the decryption key

no identity verification is built in

important

exchange private ids through a secure channel (signal, telegram, in-person, etc.).

use a vpn if you want to reduce ip exposure.

only connect with people you trust.

do not assume absolute security. this project is not formally audited.

review any modified versions of the code before using them.

while blckbx uses strong encryption and is more secure than traditional email, it is provided for educational and experimental purposes. for highly sensitive or enterprise-level communications, use professionally audited platforms.
